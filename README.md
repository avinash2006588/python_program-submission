## Installation

Check Python installation:

```bash
python --version
```

```bash
pip install numpy pandas matplotlib seaborn plotly
```

## Running the Programs

Navigate to the required experiment:

```bash
cd Experiment-1
```

Run a Python program:

```bash
python program_name.py
```

For programs that generate graphical output, the visualization will open in a separate window.
